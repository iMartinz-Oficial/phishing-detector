📚 Acerca del Proyecto

Phishing Detector es una aplicación web que utiliza Inteligencia Artificial para detectar correos electrónicos fraudulentos tipo phishing.

🤖 ¿Qué es Phishing?

El phishing es un tipo de ciberataque donde los atacantes envían correos falsificados que aparentan ser de empresas legítimas (bancos, tiendas, redes sociales) para engañar a las víctimas y obtener información sensible como contraseñas, números de tarjeta de crédito o datos personales.

Este sistema analiza automáticamente los correos y determina si son legítimos o fraudulentos con un 96% de precisión.

⚙️ ¿Qué hace la aplicación?

El sistema analiza 4 componentes del email:

  • Remitente: Verifica si el dominio del email es sospechoso
  • Asunto: Detecta palabras de urgencia o tácticas de manipulación
  • Contenido: Usa ML para identificar patrones de phishing
  • Enlaces: Analiza las URLs en busca de dominios sospechosos

🧠 ¿Cómo funciona la IA?

1. Entrenamiento del Modelo

El modelo se entrenó con más de 160,000 correos electrónicos etiquetados (legítimos y phishing) del dataset público de HuggingFace.

2. Preprocesamiento de Texto

Cuando analizamos un email, primero limpiamos el texto:

  • Convertimos a minúsculas
  • Eliminamos URLs y emails
  • Removemos "palabras vacías" (the, is, and...)
  • Solo mantenemos palabras relevantes

3. Vectorización TF-IDF

El texto limpio se convierte en números usando TF-IDF (Term Frequency - Inverse Document Frequency). Esto asigna un peso a cada palabra según qué tan importante sea para identificar phishing.

4. Clasificación con Logistic Regression

El modelo de Logistic Regression analiza el vector de características y calcula una probabilidad de que el email sea phishing.

Flujo: Email → Limpieza → TF-IDF → Modelo ML → Probabilidad (%)

☁️ ¿Cómo se despliega?

La aplicación se despliega en Vercel, una plataforma de cloud computing:

  • Frontend: Archivo HTML/CSS estático served por Vercel
  • API: Función Python serverless que carga el modelo ML
  • Modelos: Archivos .pkl con el modelo entrenado y el vectorizador

Cuando el usuario envía un email, el frontend lo manda a la API, que lo procesa con el modelo y devuelve el resultado.

📊 Métricas del Modelo

  • Precisión: 96.42% - De todos los correos analizados, el 96% se clasificaron correctamente
  • Precision (Phishing): 95.43% - De los marcados como phishing, el 95% realmente lo eran
  • Recall: 96.83% - Detectamos el 97% de todos los phishing reales

🔒 Limitaciones y Recomendaciones

Este sistema es una herramienta de ayuda, no un sustituto del juicio humano. Siempre:

  • Verifica el remitente directamente antes de actuar
  • No hagas clic en enlaces de emails sospechosos
  • No proporciones información personal por email
  • Cuando dudes, contacta a la empresa por otros medios
